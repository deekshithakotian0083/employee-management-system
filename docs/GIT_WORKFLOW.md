## 2. Feature branch with two commits

```powershell
git checkout -b feature/flask-docker
git rm -r --cached __pycache__            # stop tracking bytecode (see .gitignore)

git add Dockerfile .dockerignore flask_app.py requirements.txt
git commit -m "Add Flask app and Dockerfile for jenkins-flask-app:1.0"

git add Jenkinsfile .gitignore README.md docs/GIT_WORKFLOW.md
git commit -m "Add Docker build/run stages to Jenkins pipeline and .gitignore"

git push -u origin feature/flask-docker
```

Commit 1 adds the application and its container image definition. Commit 2 wires
it into CI and adds repo hygiene and documentation. Each commit is one idea.

## 3. Pull request

Open a PR from `feature/flask-docker` into `Master`
(`gh pr create --base Master --head feature/flask-docker`).

## 5. Merge conflict exercise (separate branches)

```powershell
git checkout Master
git checkout -b conflict-a
# edit the first line of README.md to: "# Employee Management System (Console)"
git commit -am "README: title mentions console"

git checkout Master
git checkout -b conflict-b
# edit the same line to: "# Employee Management System (Flask + Docker)"
git commit -am "README: title mentions Flask and Docker"

git checkout conflict-a
git merge conflict-b          # CONFLICT (content): Merge conflict in README.md
```

README.md now contains markers:

```
<<<<<<< HEAD
# Employee Management System (Console)
=======
# Employee Management System (Flask + Docker)
>>>>>>> conflict-b
```

Resolve by keeping both intents, delete the markers:

```
# Employee Management System (Console, Flask and Docker)
```

```powershell
git add README.md
git commit                    # completes the merge
git log --oneline --graph
```

**Notes to submit:** both branches changed line 1 of README.md, so Git could not choose.
Resolution combined both titles, so neither change was lost. Verified with
`git diff conflict-a~1 conflict-a` and by rerunning the tests.

## 6. `.gitignore` entries

| Entry | Why |
|-------|-----|
| `__pycache__/`, `*.py[cod]`, `.pytest_cache/` | Generated bytecode/caches; machine-specific and noisy in diffs. |
| `.venv/`, `venv/`, `env/` | Local virtual environments; rebuilt from `requirements.txt`. |
| `*.zip` | Package built by the Jenkins "Package Artifact" stage. |
| `reports/*` + `!reports/.gitkeep` | Test reports are build output, but the folder itself stays tracked. |
| `container-status.txt`, `flask-container-status.txt` | Temp files written by pipeline verify stages. |
| `.env`, `*.pem` | Secrets must never be committed. |
| `.vscode/`, `.idea/`, `.DS_Store`, `Thumbs.db` | Editor/OS clutter specific to each developer. |

Note: `.gitignore` does not affect files already tracked. `__pycache__/*.pyc` is tracked
today, so run `git rm -r --cached __pycache__` once (in the commit above).
